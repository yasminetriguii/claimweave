# Public project comparison

Reviewed November 8, 2026. LaunchPad's project gallery displayed that it had not been published. Therefore this review cannot establish what current entries do or rank ClaimWeave against this year's field.

The public participant list was sorted by project count. The first visible portfolio page of each of the 20 highest-project-count participants was inspected, covering 455 project cards. Five closely related projects were read in detail. This is a targeted benchmark, not a review of all 480 participants, all historical pages, or unpublished work. Counts are observations at the time of review, not a quality ranking.

| Published project | Relevant strength in its description | Implication for ClaimWeave |
|---|---|---|
| [Change Radius](https://devpost.com/software/change-radius) | Paths connecting software changes to affected verification and documents | A dependency graph alone is not distinctive; expose a useful next action |
| [Ripple](https://devpost.com/software/ripple-d125g6) | Simulated changes, scoped decisions, recovery, and repeatable causal traces | Consent and change propagation need robust failure handling and clear bounds |
| [Fineprint](https://devpost.com/software/fineprint-1mk79f) | Source-linked benefit-notice evidence with explicit uncertainty | Avoid inferred deadlines or eligibility; retain review states |
| [ClaimGuard AI](https://devpost.com/software/claimguard-ai-afbdmi) | Claim documents, policy matching, and investigation-oriented evidence | Missing-evidence dashboards are already common; make coordination value measurable in the demo |
| [AccessGraph](https://devpost.com/software/accessgraph) | Clinical evidence matched to authorization criteria and next steps | Readiness is an existing concept; focus on multi-program refresh planning and policy regression |

These observations are based on their published claims, not independent source or deployment audits. Their unmentioned capabilities may overlap further. No competitor code or assets were copied.

## Resulting product decisions

- Add a minimum collection-step planner across program checks, with an inspectable four-option synthetic catalog and exact enumeration.
- Add a 12-case policy regression bench with 36 program comparisons and downloadable inputs and traces.
- Keep uncertainty and applicant consent separate from evidence collection.
- Build a short judge path that demonstrates concrete behavior before explaining the architecture.
- Disclose synthetic assumptions and AI coding assistance explicitly.

ClaimWeave's differentiation remains a product hypothesis. This review does not support a “first ever,” guaranteed-win, or proven-impact claim.
