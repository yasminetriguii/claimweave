BUILT WITH A SPECIFIC QUESTION

What breaks when evidence changes?

YC’s “Plaid for Government Benefits” request describes reusable, consent-based records. Reusable verification already exists. ClaimWeave explores a smaller developer-facing question: can a reviewer inspect evidence freshness, conflicting claims, purpose-specific consent, and policy version changes in one reproducible workspace?

Honest boundaries

No live integrations, identity verification, OCR, runtime AI, cryptographic proofs, or actual government rules. Source names and records are fabricated. Import is for synthetic JSON only. Export is a local download, not a submission. The scenario engine never makes a real eligibility decision. Withdrawing consent blocks future in-app exports; it cannot retract a file already downloaded.
